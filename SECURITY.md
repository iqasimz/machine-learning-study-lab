# Security

This is a static educational website. It does not accept accounts, uploads or API keys, train models, or run Python examples. In-page JavaScript demonstrations calculate illustrative values in the browser.

Review code examples before running them yourself. Linked software, papers and websites are independent resources with their own policies and licenses.

If you find an unsafe script, unexpected external request or accidental personal information, report it privately through the repository owner's GitHub profile rather than posting sensitive details in a public issue.
