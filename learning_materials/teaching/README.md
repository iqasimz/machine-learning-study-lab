# Main course explanations

These chapters supply the main explanation displayed inside each existing lesson. The same reader is used by the sidebar and Interactive mode. They are not an optional reading list or an audit pack.

| `natural_language.md` | P6–P7, N01–N24 |
| `language_models.md` | T0–T8, R1–R9 |

Each `## ID. Title` heading identifies an existing lesson. Subheadings within it are ordinary explanation sections. Sources beside each lesson identify textbooks, original papers, or official implementation documentation; the calculations and prose are written for this course rather than copied from those works.

The worked browser examples remain in the reader profiles and JavaScript implementations. They illustrate calculations using fixed values. Original topic Markdown supplies longer derivations, assumptions, and settings notes. Real fitted runs are separate evidence. Do not imply that the browser illustrations trained a model or produced a benchmark result.

When editing, check the assembled `reader.reading.lesson_markdown`, not only the file. Its contents participate in the reader fingerprint, so the interactive course can notice a changed edition. Preserve the existing diagrams and numerical conventions unless there is a justified correction. Necessary definitions belong before their use; notes can extend an explanation but should not hide its premise.

Source versions: Jurafsky and Martin's linked chapters are the August 2026 draft; D2L is the published 1.0.3 online book; scikit-learn links use the 1.7 documentation where implementation details matter; PyTorch references use 2.9 where available. Moving vendor documentation is supplementary and should be rechecked when changing a dependent explanation.

The course is self-contained enough to read before opening its sources. External readings provide further derivation and exercises, not permission to omit the explanation here. Link availability checks are not evidence that every sentence is supported, and passing numerical tests is not a student-learning study.
