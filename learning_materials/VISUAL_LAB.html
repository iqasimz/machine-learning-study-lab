1. Scores become probabilities—not truth

Raise one score or change temperature. Which outcome is favoured? How does the loss change if you select a different correct target?

pᵢ = exp(zᵢ / temperature) / sum(exp(zⱼ / temperature))
Loss = −log p(correct target)

Entropy measures uncertainty in this distribution. It does not measure factual correctness. Units here are natural-log nats.

3. A nearest vector is not necessarily supporting evidence

Move a query through an artificial two-dimensional space. Compare cosine with dot product. These coordinates do not represent real semantic embeddings.

Document vectorCosineDot

A zero query has no cosine direction. Similarity alone cannot check a negation, a citation, a permission or a factual claim.

advantageᵢ = (rewardᵢ − group mean) / (population standard deviation + 10⁻⁸)

Try 1, 1, 1, 1. Identical rewards provide no within-group quality ranking. Real trainers differ in normalization and objectives.

5. Weight storage and KV cache are different budgets

Raw weight bytes = parameters × bits / 8
KV bytes = 2 × layers × sequences × cached tokens × KV heads × head width × 2 bytes

This assumes a conventional uncompressed FP16/BF16 KV cache. It excludes quantization metadata, activations, workspace, allocator overhead, runtime, operating system and training optimizer state. It is a lower-bound arithmetic illustration—not a hardware recommendation or fit guarantee.
