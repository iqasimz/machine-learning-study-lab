# Machine learning

Read in order unless the prerequisite checks are already comfortable. These are stage-1 lesson drafts; the related experiments are planned, not runnable through the website yet.

- **ML01** — [Problems, data and baselines](01_PROBLEMS_DATA_AND_BASELINES.md). Define available inputs and target before fitting. Choose independent split units and an honest baseline.
- **ML02** — [Features and preprocessing](02_FEATURES_AND_PREPROCESSING.md). Fit preprocessing within each training fold. Compare numeric, categorical and text representations.
- **ML03** — [Linear regression](03_LINEAR_REGRESSION.md). Derive squared-loss gradients and least squares. Distinguish prediction, residual and uncertainty.
- **ML04** — [Logistic and multiclass classification](04_LOGISTIC_AND_MULTICLASS_CLASSIFICATION.md). Calculate log loss and a threshold decision. Distinguish binary, multiclass and multilabel tasks.
- **ML05** — [Regularization and model selection](05_REGULARIZATION_AND_MODEL_SELECTION.md). Explain bias/variance and selection error. Fit regularization without selecting on test data.
- **ML06** — [Neighbours, kernels and SVMs](06_NEIGHBOURS_KERNELS_AND_SVM.md). Compute neighbour votes and a margin penalty. Explain C/gamma and scale sensitivity.
- **ML07** — [Probabilistic classifiers](07_PROBABILISTIC_CLASSIFIERS.md). Calculate a naive Bayes posterior ratio. Compare class-conditional versus conditional-discriminative fitting.
- **ML08** — [Trees and random forests](08_TREES_AND_RANDOM_FORESTS.md). Calculate a split's impurity gain. Explain feature subsampling and correlated tree errors.
- **ML09** — [Boosting and model combinations](09_BOOSTING_AND_ENSEMBLES.md). Explain additive fitting versus independent bagging. Design leakage-free stacking and matched tuning budgets.
- **ML10** — [Metrics, calibration and uncertainty](10_METRICS_CALIBRATION_AND_UNCERTAINTY.md). Calculate class metrics and paired uncertainty. Separate confidence calibration from ranking and coverage.
- **ML11** — [Clustering and mixture models](11_CLUSTERING_AND_MIXTURES.md). Carry out a k-means assignment/update. Compare hard clusters, mixture responsibilities and density clusters.
- **ML12** — [Dimension reduction and anomaly detection](12_DIMENSION_REDUCTION_AND_ANOMALIES.md). Calculate PCA projection and reconstruction. Distinguish visualization, anomaly scores and verified faults.
- **ML13** — [Time series and forecast evaluation](13_TIME_SERIES_AND_FORECASTING.md). Build causal lag features and a seasonal baseline. Use forward evaluation with a stated forecast horizon.
- **ML14** — [Recommendation and sequential decisions](14_RECOMMENDATION_AND_SEQUENTIAL_DECISIONS.md). Calculate a factorized recommendation score. Distinguish supervised ranking, bandit feedback and multi-step returns.
- **ML15** — [Generalization and probabilistic prediction](15_LEARNING_THEORY_AND_PROBABILISTIC_PREDICTION.md). Interpret a finite-class generalization bound. Explain a Gaussian-process prediction and its assumptions.
- **ML16** — [A complete ML experiment](16_COMPLETE_ML_EXPERIMENT.md). Design and defend a reproducible baseline comparison. Package the preprocessing pipeline, metrics and limits.
